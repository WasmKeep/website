Stateful actors in any language, on servers you own.

WasmKeep runs many small actors, each a WebAssembly component with its own SQLite database.

Idle actors leave memory and wake in about a millisecond; one event at a time, no locks.

Nodes share an object storage bucket, so an actor's data outlives the node it ran on.

The language wall

Each tile is a counter actor written in that language, called by this site's front. Add one: the count is stored in that actor's own database.
